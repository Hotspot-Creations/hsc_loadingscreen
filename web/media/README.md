# Media folder

Place optional, copyright-cleared media here.

- Background video example: `background.mp4`
- Music example: `night-drive.mp3`

After adding a file, enable and reference it in `../config.js`. Keep media compressed so players do not have to download an unnecessarily large resource.

External music URLs can instead be configured directly in `../config.js` without adding a music file here. Use actual audio-stream/file URLs rather than links to music pages.
